Hud · dock (global or workspace set)
  • Projection: x = ox + (gx − gy)·32, y = oy + (gx + gy)·16 − z. Paint back-to-front by gx + gy.
  • Buildings = workspaces (roof colour, lit windows = working). Desks = agents; orchestrator gets the ringed platform.
